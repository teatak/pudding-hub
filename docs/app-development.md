# App development has moved

App packages were replaced by plugins. This old URL remains a migration pointer, not a separate development guide.

- [Plugin development](plugin-development.md)
- [中文插件开发](plugin-development.zh-CN.md)
- [Developer documentation](README.md)

New packages use `extensions/plugins/<name>/plugin.yaml`. Do not create a new `apps/<name>/app.yaml` package. Historical registry files remain solely for old clients.
