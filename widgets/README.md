# Legacy widgets distribution

This directory contains frozen public artifacts for older Pudding clients.
Authoring sources and future releases live in [`extensions/widgets/`](../extensions/widgets/).
Do not update packages, catalogs, metadata or artwork here. These public paths
will be retired separately; no automatic deletion date is configured.

此目录仅保留旧客户端使用的公开产物，不再维护源码或发布新版本。
开发和打包请使用 `extensions/widgets/`；旧路径后续另行下线。
