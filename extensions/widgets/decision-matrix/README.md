# 决策罗盘 (Decision Matrix)

基于“爱德华·德·博诺（Edward de Bono）六顶思考帽”模型的多视角决策研判小组件。通过将复杂的决策难题拆解为事实、收益、风险、直觉与创新对策等维度，由多位 AI 特工与人类决策者协同推演，最终由蓝帽收敛成结构化的决策矩阵与行动落地清单。

## 核心特性

- **六顶思考帽推演体系**：
  - ⚪ **白帽（客观事实）**：厘清已知数据、现状基线、资源边界与客观约束。
  - 🟡 **黄帽（收益机遇）**：发掘长远价值、最佳预期、增长空间与核心优势。
  - ⚫ **黑帽（审慎风险）**：指出致命死穴、隐蔽代价、稳定性隐患与最坏后果。
  - 🔴 **红帽（直觉体感）**：表达第一直觉、团队士气、审美好恶与心理阻力。
  - 🟢 **绿帽（突破对策）**：针对黑帽指出的风险探索替代路径与创新避险方案。
  - 🔵 **蓝帽（裁决综述）**：统揽各方权衡，计算推荐指数（0-100），输出定论与行动清单。
- **人机协同双向驱动**：
  - 支持多位 AI Agent 接收通知并分别认领思考帽席位调用 `contribute` 接口立论；
  - 亦支持人类决策员在界面手写补充观点，或一键加载经典工业级案例进行即时演练。
- **双模态沉浸视图**：
  - **决策矩阵 & 行动清单**：直观的四象限对照卡片（收益 vs 风险 vs 事实 vs 直觉），搭配可交互勾选的蓝帽行动 Checklist；
  - **思考帽研判流**：按时序记录每位特工的高清论述，支持按帽子颜色单选过滤。
- **一键导出 Markdown**：
  - 一键将研判背景、各帽子论点、推荐定调及行动待办完整导出为干净的结构化 Markdown，方便沉淀至团队知识库或 PR 说明。
