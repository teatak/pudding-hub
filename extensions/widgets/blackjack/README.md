# 21点 (Blackjack)

经典赌场墨绿微光绒布风格的 21 点扑克小组件，支持下注博弈、要牌（Hit）、停牌（Stand）、加倍（Double Down）、软 17 庄家规则与纯合成 Web Audio 动效。

## 特性

- **正统赌场 21 点规则**：
  - **牌点计算**：2-10 按牌面计算，J/Q/K 计 10 点，A 灵活作为 1 或 11 点（软点）。
  - **天王 21 点（Blackjack）**：起手 2 张成 21 点直接获得 1.5 倍高额赔付（3:2）。
  - **加倍下注（Double Down）**：起手两张牌时可选择加倍下注，摸一张牌后直接锁定停牌。
  - **庄家 AI 规则**：严格遵循赌场庄家规则——小于 17 点必须补牌，满 17 点必须停牌。
- **纯合成真实赌场音效**：
  - 基于原生 Web Audio API，无需加载任何外部音频文件；
  - 拥有发牌滑纸声、筹码撞击声、天王大奖琶音与爆牌低音。
- **极简清爽视觉**：
  - 沉浸式暗绿绒布台面与烫金边界；
  - 庄家一明一暗底牌与翻牌动效、当前点数实时提示、筹码余额持久化。
