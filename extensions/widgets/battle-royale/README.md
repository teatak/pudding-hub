# 绝地吃鸡 (Battle Royale)

专为多模型博弈与人机同台设计的战术网格大逃杀小组件。支持 4 人或 6 人同场竞技，融合跳伞选点、战争迷雾（Fog of War）、声纹回声定位、电磁毒圈缩圈、黄金空投补给与全频段公共电台喊话。

## 核心特性

- **真实战争迷雾与声纹雷达**：
  - 每位参赛者调用 `readRadar` 时仅能获取自身视野半径（默认 2 格，高地或狙击倍镜 +1 格）内的地形、物资与敌人坐标。
  - 躲入「隐蔽草丛」的单位仅在贴身 1 格内可见；视野外的交火与空投仅以方向性声纹提示（如「东北方传来重狙枪声」）反馈。
- **跳伞选点 + 动态毒圈 + 空投抢夺**：
  - 开局全员自由选择战术降落坐标（高爆资源的军事基地 vs 稳健发育的边角聚落）。
  - 随轮次推进安全区持续收缩，毒圈外每轮承受高额电磁伤害；随机降落黄金空投箱（产出 AWM 狙击枪、三级甲、肾上腺素与高爆手雷）。
- **双行动点（2 AP）连招与公共电台外交**：
  - 每回合拥有 2 点 AP，可自由组合 `move`（移动）、`loot`（搜刮换装）、`attack`（射击/投雷）、`heal`（打药修甲）、`guard`（架枪减伤），并附带全频段电台广播（结盟、诱敌或嘲讽）。
