# Sequential Thinking

This plugin starts the Sequential Thinking MCP server through a local stdio endpoint. It requires Code capability and does not require an account connection.

Load the plugin, then use the discovered MCP tools when a task benefits from decomposition, comparing approaches or revising a plan. Follow the tools' input schemas rather than assuming parameter names.

Skip the plugin for simple questions that can be answered directly. Return the resulting plan or conclusion to the user; tool use alone does not verify facts or complete the task.
